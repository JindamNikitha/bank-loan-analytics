# Bank Loan Analytics

Bank loan performance analysis using SQL, Power BI, and Tableau, completed as part of my Data Analyst training with AIVariant/ExcelR.

## Overview
Analyzed loan applications, funded amounts, interest rates, and repayment behavior to understand lending performance and risk, presented through interactive dashboards in both Power BI and Tableau.

## Key Findings
- Total loan amount: 446M across 39.7K customers
- Average interest rate: 12.02%
- ~68% of total payments came from verified borrowers
- Loan amounts grew sharply from 2M (2007) to 261M (2011)
- Grade B sub-grades held some of the highest revolving balances

## Tools Used
- SQL (MySQL) — data cleaning and querying
- Power BI — interactive dashboard and KPI reporting
- Tableau — alternate dashboard version for comparison
- PowerPoint — presentation of findings
